## ✨ The Idea

What happens when a natural form is treated as a **dynamic mathematical system**?

This project explores that question through a procedural peacock feather animation built with **Python + Manim**.

Instead of simply drawing a feather, the animation gives its components **motion, interaction and field-driven behaviour**.

```text
                    🌀 Motion Field
                         ↓
             ┌─────────────────────┐
             │  Procedural Geometry │
             └──────────┬──────────┘
                        ↓
                 Feather Elements
                        ↓
               Attraction / Repulsion
                        ↓
                 Smooth Dynamics
                        ↓
                       🦚
```

The animation experiments with a repulsion-field model where feather elements respond dynamically to their distance from a moving influence.

A simplified model:

$$
\vec F = k\frac{\vec r}{|\vec r|^p}
$$


This transforms the feather from a collection of shapes into a **responsive visual system**.

## 🚀 Run It

```bash
git clone https://github.com/janhvi11-15/MorPankh 
cd MorPankh

pip install manim

manim -pql janamastami.py MorPankh
```

For a higher-quality render:

```bash
manim -pqh janamastami.py MorPankh
```
